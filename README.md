# Launchion Landing Page

A modern landing page built with Next.js.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI:** shadcn/ui + Tailwind CSS
- **Language:** TypeScript

## Getting Started

### 1. Install

```bash
pnpm install
```

### 2. Run Development Server

```bash
pnpm dev
```

Visit [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
pnpm build
pnpm start
```
